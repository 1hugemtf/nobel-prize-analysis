# Source dataset

`nobel.csv` is preserved unchanged from the supplied DataCamp Nobel Prize project. It contains 911 recipient-award records from 1901 through 2016, with award, identity, birthplace, supplied sex, affiliation and date fields.

Four source recipient-type errors are corrected only in the notebook, by explicit laureate ID, with official references. Two individual birth dates are missing. See the main README and notebook for counting units, denominators and limitations. Source-data rights remain with their respective owners.
